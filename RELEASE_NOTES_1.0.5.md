# Systemika Studio 1.0.5

Systemika Studio 1.0.5 is a focused interface-polish release based on 1.0.4.

## Changes

- **Exact visual width alignment:** legacy table-based setting boxes now collapse their default HTML table spacing inside the dock, so their visible outer borders occupy the full shared 360 px settings width and align exactly with **Selected Variable(s)** and **Runs to compare**.
- **Two-row panel header:** the panel title plus Detach/Attach and Close controls remain on the first row. Export actions now occupy a dedicated second row directly beneath them and are aligned to the left edge of the panel header.
- Existing 1.0.4 behavior is retained, including the 378 px default panel width (105% of the 360 px settings width), icon-only Detach/Attach, 50/50 output/settings split, and SVG/CSV plot exports.

## Compatibility

No model-file format or simulation-engine changes were introduced in this release. Existing Systemika Studio models and saved output settings remain compatible.
