# Selection-aware Equations panel — Systemika Studio 1.2.1

When the Equations panel is open, it follows the current canvas selection. Select a Stock, Flow, Auxiliary, Constant, or Lookup to see only that entity's equation; select several to inspect them together. Clear the selection to view all equations. Selecting only a link, annotation, or another object without an equation keeps the full list visible. Selecting a ghost uses its original model variable.

The panel's Equation form and Sort controls remain active. The TXT, CSV, and LaTeX exports use exactly the same filtered equation rows as the preview. The underlying model and equations are not modified.
